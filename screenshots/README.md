# USIMS evidence screenshots

Capture these screenshots from a genuinely running local installation. Do not create mockups or use generated images as execution evidence.

Recommended files:

- `dashboard.png` - application dashboard with sample statistics
- `students.png` - student records and a successful student search
- `courses.png` - course catalogue and programme filters
- `registrations.png` - a student registered for a course
- `examinations.png` - examination results and assigned grades
- `invalid-marks-rejected.png` - attempted mark of 101 rejected by the database trigger
- `fee-management.png` - sample fee records and receipt references
- `erd.png` - the seven-table entity relationship diagram
- `database-verification.png` - successful output from `bash scripts/verify-database.sh`
- `backup-restore.png` - successful backup and restore demonstration

Use synthetic records only. Blur or remove names, email addresses, phone numbers, student IDs, dates of birth, addresses, payment references, credentials, and other personal or financial information before committing screenshots.

The screenshot files are evidence to be collected after running the application and database locally. Their absence does not mean the tests have passed.
